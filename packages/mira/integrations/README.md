# Integrations

One adapter per third party. Missing credentials → demo mode. The command center still boots.

| Module | Demo fallback |
| --- | --- |
| dropbox | `data/demo/inbox` |
| elastic | SQL filters |
| deepgram | typed skill API |
| visa | `Payment.is_sandbox=true` |
| zenni | HTTP contract only |
| public_data | seeded FRED-like snapshots |
